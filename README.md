# Instrument Quiz

A picture quiz for 4-year-olds: the app *says* the name of an instrument out loud and the child taps the matching picture. No reading needed.

- Open `index.html` in any browser (tablet or phone works great). No install, no internet required.
- Tap ▶️ to start, 🔊 to hear the question again, the flag to switch English / French.
- 10 rounds, a ⭐ for each first-try answer, the instrument plays its sound when found.
